    Evaluate against a CSV

    Each row is sent to Clef, and its prediction is compared with the row's correct answer.

    ColumnContents
    contextThe situation the model reasons about.
    questionThe question to answer.
    answerThe correct answer.
    options optionalCandidate answers separated by any punctuation, e.g. TRUE;FALSE;NOT GIVEN or yes|no. If empty or missing, the options are the distinct answers to the same question in the file.

    Columns can be separated by commas, tabs, semicolons, pipes or any other punctuation. Put double quotes around a field that contains the separator, and double any quotes inside it ("").
